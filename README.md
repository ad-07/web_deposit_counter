# web_deposit_counter
# Deposit Counter

Интерактивное веб-приложение на Streamlit для расчёта и визуализации накоплений во времени.

## Что делает приложение

- Симулирует рост накоплений по месяцам с учётом:
  - ежемесячных отчислений от зарплаты;
  - годовой индексации зарплаты (promotion);
  - инвестиционного дохода на текущий баланс (реинвестирование);
  - опциональной 13-й зарплаты раз в год.
- По заданной целевой сумме и горизонту (в месяцах) бинарным поиском подбирает минимальный процент отчислений от зарплаты, необходимый для достижения цели.
- Строит интерактивный график динамики накоплений (Plotly) с отметкой целевой суммы.

## Стек

- Python 3
- [Streamlit](https://streamlit.io/) — веб-интерфейс и ввод параметров
- [Plotly](https://plotly.com/python/) — интерактивная визуализация

## Установка и запуск

```bash
git clone https://github.com/ad-07/web_deposit_counter.git
cd web_deposit_counter
pip install -r requirements.txt
streamlit run main.py
```

После запуска приложение откроется в браузере по адресу `http://localhost:8501`.

## Как пользоваться

1. Введите текущие накопления и ежемесячный доход.
2. Укажите процент дохода, который планируете откладывать, ожидаемую ежегодную индексацию зарплаты и годовую доходность инвестиций.
3. Задайте горизонт накоплений (в месяцах) и целевую сумму.
4. Приложение покажет:
   - минимальный процент отчислений, необходимый для достижения цели за выбранный срок;
   - итоговую накопленную сумму при указанных параметрах;
   - график роста накоплений с отметкой целевой линии.

## Идея проекта

Проект родился из желания посчитать, сколько нужно откладывать и как долго копить, чтобы выйти на желаемый уровень накоплений — с учётом реальных факторов вроде индексации зарплаты и инвестиционного дохода, а не по упрощённой формуле.
